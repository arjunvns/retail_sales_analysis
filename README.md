Retail Sales Analysis and Forecasting

Project Overview

This project analyzes retail sales data using Python and data analysis techniques. It includes data processing, sales analysis, and a seven-day sales forecasting output.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Project Files

- "project_retail_sales.ipynb" — notebook containing the project code and analysis.
- "retail_sales_data.csv" — retail sales dataset.
- "next_7_days_forecast.csv" — output containing the next seven days of sales forecasts.

Key Work

- Data preparation and cleaning
- Exploratory data analysis
- Sales trend analysis
- Predictive modeling and forecasting

How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open "project_retail_sales.ipynb" in Jupyter Notebook.
4. Run the notebook cells in order.
